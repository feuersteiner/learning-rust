# Lesson 06 - Ownership

## Goal

Build a mental model for ownership, moves, copies, and scope-based cleanup so you can predict when values are valid.

## Concepts

- The three ownership rules
- Stack vs heap and move semantics
- `Copy` types vs moved types
- Scope ends values and runs `Drop`
